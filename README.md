# Regular Expressions for Everyone

A free, self-paced course on regular expressions for complete beginners. It is a single interactive HTML page with eight modules, a live regex tester, hands-on examples, short quizzes, and curated readings, videos, books, and games. No programming is needed for modules 1 to 6; module 7 adds Python and R.

## Contents

| # | Module |
|---|--------|
| 1 | What is a regex? |
| 2 | Character classes |
| 3 | Quantifiers: how many? |
| 4 | Anchors, boundaries, and choices |
| 5 | Groups and backreferences |
| 6 | Lookarounds and flags |
| 7 | Regex in Python and R |
| 8 | Real-world uses and pitfalls |

Each module includes a goal, a time estimate, examples you can load into the live tester, real-world uses, Python and R snippets, filterable resources, and a self-check quiz. The suggested pace is roughly 4 to 6 weeks at a few hours a week. That estimate is a rough guide, not a measured figure.

## Usage

1. Download `index.html`.
2. Open it in any modern browser. There is no build step or server, and nothing to install.

## Notes on the links

Resource links point to third-party sites and may change or disappear over time. If you find a broken or outdated link, please open an issue or a pull request.

## Contributing

Corrections, new examples, quiz questions, and resources are welcome. Please keep code examples in Python and R and prefer free resources where possible.
