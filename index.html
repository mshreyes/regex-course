Regular expressions for everyone

A hands-on course for complete beginners. Learn to find, extract, and replace text with patterns. Modules 1 to 6 need no programming; module 7 adds Python and R. Every example loads into the live tester, and each module ends with a quiz. About 4 to 6 weeks at a few hours a week (a rough guide). Check each linked site for current content.

Live tester

Uses your browser's JavaScript regex engine. Python and R differ slightly (see module 7). Flags: g all matches, i ignore case, m ^ and $ per line.
